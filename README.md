# simulasicpns

> **Status: Archived (2026)**
>
> - **Reason:** a short 2024 experiment to rebuild the CPNS simulation bot in Python; it stopped at user registration and is built on Pyrogram, which is no longer maintained (upstream archived in December 2024).
> - **Created:** 2024
> - **Successor:** development of the CPNS simulation continues in [erzawansyah/simulasi-cpns-telegram](https://github.com/erzawansyah/simulasi-cpns-telegram).
>
> The code is kept for reference only. Issues and pull requests are not monitored.

Telegram bot skeleton (Python, Pyrogram, pydantic, Supabase) forked from [pyrogram_telebot](https://github.com/erzawansyah/pyrogram_telebot). It contains the modular event handler, logging, and `/start` + `/register` commands; no question bank, practice, or test features were built. The previous README was the generic template README and has been replaced by this note.
